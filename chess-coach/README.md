# Анна Ветрова — сайт шахматного тренера

Одностраничный лендинг для тренера по шахматам: тёмная «салонная» палитра
(эспрессо, слоновая кость, состаренное золото), антиква Cormorant Garamond —
в едином стиле с соседним проектом «Гамбит».

## Запуск

Откройте `index.html` двойным кликом. Для шрифтов Google Fonts нужен интернет,
всё остальное работает офлайн. Локальный сервер (по желанию):

```bash
python -m http.server 8438
# → http://localhost:8438
```

## Разделы

Герой с ключевыми цифрами · Обо мне · Программы занятий (4 карточки) ·
Как проходят занятия (4 шага) · Стоимость (3 тарифа) · Отзывы · FAQ ·
Форма записи + контакты · Подвал.

## Что заменить на свои данные

| Что | Где |
|---|---|
| Имя, титул, рейтинг | `index.html` — поиск по «Анна Ветрова», «Мастер FIDE», «2320» |
| Фото | блок `.photo-frame` — сейчас монограмма «АВ»; замените `<div>` на `<img>` |
| Статистика (12 лет, 150+ учеников…) | секция `.hero-stats` |
| Цены | секция `#pricing` |
| Отзывы | секция `#reviews` |
| Телефон / Telegram / e-mail / город | список `.contacts` в `#contact` |
| Адрес при очных занятиях | FAQ, вопрос «Занятия онлайн или очно?» |

## Подключить отправку формы

Форма сейчас показывает экран «Заявка отправлена» без реальной отправки
(заглушка отмечена в `js/app.js`). Варианты подключения:

1. **Formspree** — создайте форму на formspree.io и добавьте в `<form>`:
   `action="https://formspree.io/f/ВАШ_ID" method="POST"`,
   а в JS уберите имитацию и оставьте обычный submit.
2. **Telegram-бот** — в обработчике `submit` отправьте `fetch` на свой
   сервер/вебхук, который шлёт сообщение в чат.
