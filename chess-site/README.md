# Гамбит — шахматный салон

Элегантный одностраничный сайт о шахматах: тёмная «салонная» палитра
(эспрессо, слоновая кость, состаренное золото), антиква Cormorant Garamond.

## Запуск

Откройте `index.html` в браузере (двойной клик). Для загрузки движка
[chess.js](https://cdnjs.cloudflare.com/ajax/libs/chess.js/0.10.3/chess.min.js)
и шрифтов Google Fonts нужен интернет.

Локальный сервер (по желанию):

```bash
python -m http.server 8000
# → http://localhost:8000
```

## Возможности

- **Партия за доской** — полные правила (рокировка, взятие на проходе,
  превращение в ферзя), игра против компьютера на трёх уровнях или вдвоём
  на одном устройстве. Компьютер — негамакс с альфа-бета отсечением
  (материал + таблицы позиций).
- **Дебютный салон** — пять классических дебютов с пошаговым проигрыванием
  на демонстрационной доске.
- **История** — путь от чатуранги до нейросетей в восьми вехах.
- Адаптивная вёрстка, поддержка `prefers-reduced-motion`, aria-live-статус партии.
