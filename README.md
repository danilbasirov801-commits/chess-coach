# Шахматные сайты

В репозитории два автономных сайта (статика, без сборки):

| Путь | Что это |
|---|---|
| [`chess-coach/`](chess-coach/) | Лендинг шахматного тренера: программы, тарифы, отзывы, FAQ, форма записи. **Титульный сайт** — корень перенаправляет сюда. |
| [`chess-site/`](chess-site/) | «Гамбит» — тёмный шахматный салон с играбельной доской (chess.js) и разбором дебютов. |

Подробнее о структуре и настройке — в README внутри каждой папки.
